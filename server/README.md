# 同期・通知サーバー(任意)

アプリ本体はサーバーなしで動きます。
このサーバーを動かすと、次の3つが使えるようになります。

1. **クラウド同期**:スマホとPCなど、複数の端末で同じ学習データを使えます。
2. **先生用リンク(常に最新)**:先生がリンクを開くと、いつでも最新の分析レポートが見られます。
3. **プッシュ通知**:アプリを閉じていても「記録が切れそう！」通知が届きます。

## 動かし方

Node.js 18 以上が必要です。

```bash
cd server
npm install
npm start
```

ブラウザで `http://localhost:8787` を開くと、アプリが表示されます。
アプリの「設定 → クラウド同期」で、サーバーのURLが自動で入ります。

## 本番で使うとき

- プッシュ通知には **HTTPS** が必要です。Render・Railway・Fly.io などのサービスに置くと、HTTPS のURLが使えます。
- 環境変数
  - `PORT`:待ち受けるポート(初期値 8787)
  - `DATA_DIR`:データの保存先(初期値 `server/data`)。サービスの「永続ディスク」を指定してください。
  - `VAPID_SUBJECT`:プッシュ通知の連絡先(例:`mailto:info@example.com`)
- 通知用の鍵(VAPID鍵)は、初回起動時に `DATA_DIR/vapid.json` に自動で作られます。消すと、登録済みの通知が届かなくなります。

## 注意

- 生徒のデータは `DATA_DIR/users/` に JSON ファイルで保存されます。個人情報を扱うため、サーバーのアクセス管理とバックアップを行ってください。
- 利用者が増えた場合(目安:数千人以上)は、データベースへの移行を検討してください。
