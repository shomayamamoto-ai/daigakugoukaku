# Weak-Point Sniper(ウィークポイント・スナイパー)

企画書「個別最適化オンライン家庭教師プログラム」の学習システムを、
スマホでもPCでも使えるWebアプリ(PWA)にしたものです。

案内役は、弱点をピンポイントでねらい撃つ見習いスナイパーのフクロウ
**「ピンポ」**(オリジナルキャラクター)です。

## できること

| 機能 | 内容 |
| --- | --- |
| 🎯 診断テスト | 志望校の受験科目と学年に合わせて出題します。高校の問題で間違えると、**前提になっている中学の単元へ自動でさかのぼり**、つまずきの根本原因を探します(中1レベルから収録)。 |
| 🗺️ 志望校別ロードマップ | 志望校(国公立・私立・高校受験)×苦手分析から、「土台の修復 → 基礎〜標準 → 過去問演習 → 直前」の4段階の計画と、週ごとにねらう単元を自動で作ります。 |
| ✅ 今日のやる事 | ロードマップの今週分から、その日のタスクを自動で作ります。 |
| 🃏 単語帳(苦手問題集) | 苦手単元の問題だけを集めたフラッシュカード。「覚えた」カードは1日→3日→7日→14日→30日…後に再出題します(間隔反復)。 |
| 👩‍🏫 先生用レポート | 科目別×思考レベル(知識・理解・応用)の正答率、根本原因の単元、生徒が選んだ誤答、教え方のポイント、口頭試問、次回30分の授業プラン、8回分(約1か月)の指導計画を出力します。印刷にも対応しています。 |
| ✏️ 質問メモ | 「わからない」を押した問題は自動でメモに入り、30分授業の最初に解決できます。 |
| 🔥 連続記録・通知 | 連続学習日数を記録します。設定時刻と夜22時に「記録が切れそう！」と通知します。7日連続ごとに、1日休んでも記録が守られる「おやすみチケット」がもらえます。 |

## ホームページ

`home.html` はサービス紹介のホームページです(企画書の内容をもとに作成)。
配色は濃紺 → 青 → 青緑のグラデーションです。
お問い合わせ先は「準備中」としているため、決まったら `home.html` の Contact 欄を差し替えてください。

## 追加した機能(第2版)

- 計算系24単元は問題を自動生成し、数字を変えて何問でも出題します。暗記系にも問題を追加しました。
- 共通テスト(中間目標)と2次試験(最終目標)の2段階のカウントダウンに対応しました。
- 募集要項の配点を入力すると、ロードマップの優先順位に反映されます。各大学の公式サイトへのリンクも表示します。
- 「先生にリンクで送る」:サーバーなしで、分析レポートをリンクで共有できます(閲覧のみ)。
- 学校の定期テスト・模試の結果を記録でき、間違えた単元が分析に反映されます。
- 先生用レポートで、口頭試問の結果を記録できます。説明できなかった単元は単語帳の宿題になります。
- 任意の同期サーバー(`server/`)を動かすと、複数端末の同期・常に最新の先生用リンク・アプリを閉じていても届くプッシュ通知が使えます。くわしくは `server/README.md` を見てください。

## 使い方

1. `index.html` があるフォルダをWebサーバーで公開します(GitHub Pages などで無料公開できます)。
   - 手元で試す場合:`python3 -m http.server 8000` を実行し、ブラウザで `http://localhost:8000` を開きます。
2. 初回にニックネーム・学年・志望校・1日の勉強時間を入力します。
3. 診断テストを受けると、ロードマップと単語帳が自分専用に変わります。
4. 家庭教師の先生には、「設定 → データを書き出す」で出力したファイルを渡します。
   先生は「先生用 → 生徒データ読込」で読み込むと、分析レポートを見られます。

## ファイル構成

```
index.html            画面の入口
css/style.css         デザイン(スマホ対応・ダークモード・印刷対応)
js/data/units.js      単元・問題データ(中1〜高3、6教科・57単元・173問)
js/data/schools.js    志望校データ・時期別/科目別の勉強法・出典
js/engine.js          分析・ロードマップ・単語帳・連続記録のロジック
js/notify.js          通知(リマインド)
js/app.js             画面表示とキャラクター
sw.js                 オフライン対応・バックグラウンド通知
```

問題や単元を増やすときは `js/data/units.js` に追記してください。
書式はファイル冒頭のコメントに書いてあります。

## 注意点(現時点の制約)

- **入試情報は「傾向」レベルです。** 科目・配点・日程は毎年変わるため、必ず各大学・各都道府県の最新の募集要項で確認してください。
- **サーバーを動かさない場合、データは端末のブラウザ内に保存されます。** 先生への共有は「リンクで送る」で行えます。
- **アプリを閉じていても通知を届けるには、`server/` を HTTPS で公開する必要があります。** サーバーがない場合は、カレンダー(.ics)への登録で代用できます。
- 暗記系の単元は1単元6〜7問です。実運用では、引き続き問題の追加が必要です。
